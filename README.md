## Architectural Highlights
- **Design Philosophy**: Minimal, near-black (`#08090D`) and dark charcoal (`#111318`) canvas with soft white typography (`#F5F6FA`), muted gray (`#A1A5B0`), and vivid Electric Blue accents (`#3157E8`).
- **Performance**: Built with Vite, React 18, and Tailwind CSS. Zero bloated 3D libraries; delivers sub-second load times.
- **Conversion Systems**:
  - Editorial 6-problem opportunity cost section articulating commercial risks.
  - 3 business-first service pillars with tangible deliverables and direct inquiry hooks.
  - Transparent 4-step execution timeline from Discover to Launch.
  - Interactive project inquiry form with client-side validation, multi-currency budget selector (USD, GBP, EUR, AED, INR), and direct email fallback.
  - Configurable floating WhatsApp direct contact trigger.
- **Accessibility & SEO**: WCAG AA compliant contrast, semantic HTML5, keyboard navigation, `prefers-reduced-motion` support, OpenGraph metadata, and JSON-LD schema markup.

## Getting Started

### Prerequisites
- Node.js (v18+)

### Development Server
```bash
npm install
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```

### One-Click Deployment
To deploy to **Vercel** or **Netlify**:
```bash
npx vercel
# or
npx netlify deploy --prod
```
